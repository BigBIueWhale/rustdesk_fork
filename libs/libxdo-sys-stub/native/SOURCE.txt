Its native files match those upstream blobs. The two-entry Debian patch set
preserves the xdo_t ABI and records the upstream version. The ABI fields are
retained here; the version header is fixed rather than derived from the clock.

Local changes: trailing horizontal whitespace normalization; Debian's unused
modmap/keymap ABI fields; request-map destruction uses XkbFreeKeyboard instead
of XkbFreeClientMap, so the owned enclosing descriptor is freed as well;
unused active-modifier collection/clear/restore APIs and mouse-event collection
are removed. Mouse events retain the native input-state mask. Scratch-key lookup
queries the inclusive range only for unmapped symbols, requires a wholly unused
row, retains and restores its full mapping, and retires the query on every path.
Context construction requires XTEST before allocations or a single XKB snapshot
and checks that snapshot before publishing the character map. Caller-supplied
display ownership transfers only on success; the display opened by xdo_new
is retired after construction failure.
Core-width sizing, repeated live symbol lookup and the private modifier traversal
are removed in favor of the snapshot's types, symbols and real-modifier map.
Keyboard input accepts one validated Unicode text scalar as a matched pair.
The compound string parser, locale-based text entry, alias table and generic
key-list API are removed. Text pairs resolve once and retain the same scratch mapping
through press and release, then restore its full row and retire the query once.
Enigo supplies Rust characters. The native receiver rejects invalid scalars and
unsupported controls before input, maps tab and line endings explicitly, and
converts other scalars to Latin-1 or Unicode keysyms. Raw keycodes, caller-selected
keysyms and separate press/release actions are absent. Unused per-symbol Unicode
conversion/storage and its xkbcommon dependency are removed.
Unused window property, class and urgency mutation APIs are removed.
Every key request checks one XKB state snapshot before mapping or input effects;
both text legs retain its verified restoration group. Failed queries and
out-of-range returned groups are errors without scratch or input effects.
Required modifiers resolve once into eight stack codes before input effects.
The native modifier-map query is shape/range checked and retired before any
group or key change; absent required rows refuse. Both click legs use the same
codes, and requests with no required modifiers acquire no modifier map.
Window-management actions, their wait and size-hint APIs, interactive pointer-grab
selection, desktop/viewport mutation and client/window termination are removed.
Unused window/desktop/property/name/client queries, polling, repeated-click and
feature APIs and the entire regex window-search module are removed. Cursor
coordinates use only the native pointer query. Keyboard and button input use
only XTEST on the context display, with server-owned focus, pointer and grab
routing. Caller-selected windows, directed XSendEvent input, focus-routing
helpers and the unused native click helper are removed. The provider has eleven
context, version, input and cursor/state exports and no Xinerama dependency.
Absolute movement derives the selected root from the retained Display; its API
has no separate caller-selected screen index or duplicate screen cache.
The fixed fork version is 3.20160805.1-rustdesk16.
The BSD redistribution notice is retained in COPYRIGHT and packaged with the
library. Source provenance is not a claim that all native behavior is validated.
