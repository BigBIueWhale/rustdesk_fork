Its native files match those upstream blobs. The two-entry Debian patch set
preserves the xdo_t ABI and records the upstream version. The ABI fields are
retained here; the version header is fixed rather than derived from the clock.

Local changes: trailing horizontal whitespace normalization; Debian's unused
modmap/keymap ABI fields; request-map destruction uses XkbFreeKeyboard instead
of XkbFreeClientMap, so the owned enclosing descriptor is freed as well;
unused active-modifier collection/clear/restore APIs and mouse-event collection
are removed. Mouse events retain the native input-state mask.
The fixed fork version is 3.20160805.1-rustdesk2.
The BSD redistribution notice is retained in COPYRIGHT and packaged with the
library. Source provenance is not a claim that all native behavior is validated.
